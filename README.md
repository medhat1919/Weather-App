☀️ Simple Weather App
A modern and responsive web application that displays real-time weather information for any city in the world. This project demonstrates proficiency in fetching data from external APIs and creating a dynamic user interface.

✨ Features
🌍 Current Weather: Display temperature, sky conditions, and humidity for your chosen location.

🔍 City Search: Look up the weather for any city worldwide.

📱 Responsive Design: The app works perfectly on phones, tablets, and desktops.

🎨 Attractive Interface: A simple and clean design that reflects the current weather.

💻 Technologies Used
HTML: The foundation for the app's structure.

CSS: For styling and visual presentation.

JavaScript: The core logic for managing the app, interacting with the API, and updating the UI.

Fetch API: For retrieving data from external weather services.
